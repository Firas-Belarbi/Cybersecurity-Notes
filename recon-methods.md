# Recon & Enumeration Methods

## What is Recon?
Reconnaissance is the process of gathering information about a target before attempting any exploitation.

## Passive Recon
(No direct interaction with the target)
- Google Dorking
- WHOIS lookup
- DNS lookup (NS, MX records)
- Checking subdomains
- Finding emails related to the domain
- Identifying technologies used by a website (WhatWeb, Wappalyzer)

## Active Recon
(Direct interaction with the target)
- Nmap scanning
- Port scanning
- Service version detection
- OS detection
- Directory enumeration (Gobuster, Dirsearch)
- DNS enumeration
- Checking open ports & running services

## Tools Used
- `nmap`
- `whatweb`
- `gobuster`
- `dirsearch`
- `whois`
- `dig`
